# Primer Parcial – Sistema de Gestión de Patrimonio Judicial (Base)
Para poder iniciar el proyecto primero se debera clonar el repositorio o descargar el archivo .zip.
Luego de haberlo clonado se debera realizar la instalacion de las dependencias para que el servidor pueda levantarse 
Para esto utilizaremos el comando de npm i (En caso las dependencias ya esten instaladas no se debera de hacer este paso)
Luego para levantar el servidor debera configurar en .env segun las variables que se detallan en el .env.example.
Y ahi el proyecto debera funcionar correctamente.
